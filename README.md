# Asteroids

Learning project for Boot.dev’s Build Asteroids using Python and Pygame course.

Current lesson: [Installation](https://www.boot.dev/lessons/7228cde1-e519-4ee4-920e-1c50011197bb).

## Environment

- Python 3.13 (selected in `.python-version`)
- Pygame 2.6.1
- Dependencies locked in `uv.lock`

```sh
uv sync
source .venv/bin/activate
uv run -m pygame
```

The Pygame module check is expected to print its version and exit with code 1.
Run the submission command shown in your Boot.dev lesson when ready.

Only project setup is included. `main.py` is the default uv starter; the game is yours to build.
